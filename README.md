# Scavare

Um website criado para uma industria que busca mostrar para seus clientes e parceiros seu processo de ponta a ponta.

## 🌐 Visualize o projeto:

**[Ver Projeto Online](https://mrvitiniski.github.io/Scavare/)**


## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação semântica
- **CSS3**: Estilização
- **JavaScript**: Funcionalidade interativa
- **jQuery**: Manipulação DOM e manipulação de eventos
- **ScrollReveal**: Animações de scroll
- **Font Awesome**: Ícones
- **Google Fonts**: Fontes
