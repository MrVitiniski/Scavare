**Scavare Mineração: Onde a tecnologia encontra a eficiência. Conheça nossa operação integrada e o compromisso com a qualidade absoluta.**

Este website foi desenvolvido para ser uma vitrine tecnológica da cadeia produtiva da Scavare, projetado para conectar parceiros e clientes à nossa excelência operacional de ponta a ponta.

## ✨ Diferenciais Técnicos

- **Design Premium:** Interface moderna utilizando conceitos de *Glassmorphism* e alta fidelidade visual.
- **Ultra Responsivo:** Ajuste fino para dispositivos móveis, garantindo navegação perfeita em telas como a do iPhone 15.
- **Módulo 3D Interativo:** Seção "Empresa" com sistema de rotação de cards que alterna fotos e conteúdos dinamicamente.
- **Navegação Inteligente:** Menu flutuante estilo "App" e scroll suave entre as seções.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Marcação semântica e acessível.
- **CSS3**: Estilização avançada com Variáveis, Flexbox e Grid.
- **JavaScript (ES6+)**: Lógica de interação e controle de estado.
- **GSAP & ScrollTrigger**: Motor de animações de alta performance para efeitos de scroll e transformações 3D.
- **Font Awesome**: Biblioteca de ícones profissionais.
- **Google Fonts**: Tipografia refinada (Montserrat).
